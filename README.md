# RoomMate 🏠

App de gestión de aseo y convivencia para estudiantes de la Universidad Nacional de Colombia.

## Funcionalidades
- Turno diario de aseo con ciclo equitativo de 4 semanas
- Calendario mensual interactivo
- Vista semanal con distribución de días
- Gestión de implementos del hogar por ciclos
- Registro de multas con historial
- Cumpleaños de cada persona
- Mensajes motivacionales rotativos
- PWA instalable en celular

## Stack
- HTML/CSS/JS puro (sin frameworks)
- Supabase (base de datos)
- Vercel (hosting)

## Despliegue
1. Sube este repositorio a GitHub
2. Conecta el repo en vercel.com
3. La carpeta de salida es `public/`
4. ¡Listo!
